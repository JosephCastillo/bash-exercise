# 🐚 Bash Scripting Projects - freeCodeCamp Practice

Este repositorio contiene la solución a los proyectos prácticos desarrollados para consolidar lo aprendido en el módulo **Bash Scripting** dentro de la certificación de *Relational Databases* de **freeCodeCamp**.

Los scripts están diseñados y probados para ejecutarse en entornos Linux (Ubuntu/Debian).
